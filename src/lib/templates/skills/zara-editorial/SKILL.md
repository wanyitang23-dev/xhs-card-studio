【模板: 深绿粉编辑风】
【意图】把品牌观点、趋势解读、商业复盘和生活方式内容做成克制、有时装杂志感的小红书竖版图文。

【结构 — 硬性要求】
- 无框架、无 JS。`body` 内只有一个 `.deck`，纵向排列若干 `.card`，卡间距 24px；`.deck` 不加外层 padding，避免预览时形成一圈边框。
- `*{box-sizing:border-box}`；每张卡固定 `width:1080px;height:1440px;overflow:hidden;position:relative`。
- 卡片用 72-88px 内边距，骨架为：顶部等宽标签和页码 → 主内容 → 底部署名/主题词和页序。
- `.deck` 与 `.card` 使用 `margin-inline:auto`，窄窗口中不能因 flex 居中而裁掉左侧。
- 内容装不下时先降低标题和正文字号，再调整网格；不得让正文、页脚或装饰超出卡片。

【配色】
- 主深绿 `#2e4a2a`，更深绿 `#243a21`，辅助绿 `#3a5a36`。
- 柔粉 `#e89cb1`，深粉 `#d27e96`；奶油纸色 `#efe7d4`，次级纸色 `#e6dcc4`。
- 浅底正文用近黑 `#1a1a17`；深绿底正文用奶油色，强调文字用柔粉。
- 整张卡只采用一种主底色。不要渐变、玻璃拟态、荧光色和大面积阴影。

【字体与排版】
- 标题用 `Noto Serif SC` / `Source Serif 4` / Georgia 衬线体，500-700 字重；中文正文也优先用衬线体。
- 标签、数字、页码用 `JetBrains Mono` 等宽体，大写英文可用 0.12-0.18em 字距。
- 封面标题 116-148px、行高 0.98；内容标题 68-92px；正文 30-38px、行高 1.5-1.65。
- 标题宁可断成 2-4 行，也不要压成细小的一行。中英文混排时保持明显的字号层级。

【版式语言】
- 封面：深绿底、柔粉巨型衬线标题；右上角细线圆形编号；页脚用等宽小字左右对齐。
- 封面只放主标题、短副标题和一个小标签。**不要把整段正文塞进封面**，也不要在正文下方再做一组重复摘要卡。
- 内容页从以下版式中按内容选择，不要每页重复同一种：
  1. 奶油底纵向列表、2×2 或一大两小信息格；深绿、粉、描边奶油块交替。
  2. 柔粉整卡观点页；一句核心判断占据视觉中心，底部补来源或章节信息。
  3. 奶油底实践页；标题和短解释通栏，下方用 3-4 条纵向编号行展开。
  4. 深绿底数据页；1-3 条纵向数据证据，每条是“大数字 + 标签 + 解释”，柔粉只标关键数据。
  5. 奶油底步骤页；编号卡片交替使用描边、粉底和深绿底。
- **手机端最多两列。** 禁止三列或更多横排小卡；三个项目用纵向三行，或做成上二下一的 2+1 网格，第三项通栏。
- 非封面页必须有完整的信息组：标题 + 一段解释，或标题 + 2-4 个项目。不要只放一个大词和装饰圆，留下超过约 35% 的无意义空白。
- 大标题必须来自用户内容。`Mini`、`Smaller form`、`Version`、`Region`、`Cadence` 这类演示稿装置词不能成为主视觉。
- 英文只作为 16-22px 的等宽小标签；除非用户原文就是英文，不得用英文替代中文标题和正文。
- 每条信息只出现一次。禁止先原样铺一整段正文，再把同一段拆成下方 feature / KPI / 标签重复展示。
- 不要用负 margin 把标题卡跨在两个大色块之间。标题和承载它的背景必须在同一个正常流容器内。
- 形状以直角和 4-10px 小圆角为主；边框 2px。不要做成常见的圆润马卡龙卡片。
- 装饰只用细线、圆形编号、色块和少量规则网格；所有纯装饰必须绝对定位，不能挤占正文。

【收尾】
- 收尾卡优先用深绿底，柔粉大标题；下方用 2-3 条纵向信息行总结原文中的要点。
- 页脚署名严格使用任务给出的账号；没给账号时使用内容关键词，不复制示例文案。
