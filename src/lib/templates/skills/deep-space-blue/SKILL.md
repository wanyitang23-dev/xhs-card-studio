【模板：深空蓝科技图谱】
【意图】把科技观点、AI 方法论、产品解析、研究笔记和专业知识，转成克制、精密、有空间纵深的小红书竖版图文。

【结构 — 硬性要求】
- 无框架、无 JavaScript。`body` 内只有一个 `.deck`，纵向排列若干 `.card`；预览卡间距 24px，卡片外不得出现黑色粗框。
- 每张卡固定 `width:1080px;height:1440px;overflow:hidden;position:relative;box-sizing:border-box`，内容安全区为左右 80px、顶部约 76px、底部约 68px。
- 卡片骨架为：顶部英文坐标标签 → 主内容区 → 底部主题词与页码。页脚使用正常 flex 流和 `margin-top:auto`，不得用坐标硬压在底部。
- 页面数量服从用户选择；自动模式按正文长度决定。保留原文时只调整分页，不改写、删减或补写。
- 正文结构优先使用 flex 与 grid；绝对定位只用于星点、十字、光斑和细线等纯装饰。

【核心视觉 DNA】
- 主背景为近黑 `#030506`；使用深蓝 `#071f62`、高亮蓝 `#0755dc` 和青色 `#19d7d1` 构成位于画面中部的椭圆光核。
- 文字使用冷白 `#f1f7f7`；辅助文字用 `rgba(224,239,241,.64)`；分隔线用 `rgba(226,246,247,.42)`。
- 光核由 2–3 层 CSS `radial-gradient` 组成，中心明亮、边缘自然消失在黑色空间中。不要使用高饱和霓虹描边或满屏发光。
- 背景可加入极少量星点、细微划痕质感和十字坐标标记；每页装饰不超过 3 个，不得覆盖正文。
- 不使用圆润玻璃卡片、彩色胶囊、厚重阴影和大面积白色面板。信息层级主要依靠字号、留白、细线与窄体字重建立。

【字体与排版】
- 英文、数字和中文标题优先使用 `IBM Plex Sans Condensed`，中文回退 `Noto Sans SC` / `PingFang SC`。
- 封面标题约 104–114px、200–300 字重、行高 0.98–1.08；内容标题约 72–88px；正文约 26–32px、行高 1.55–1.7。
- 英文标签与坐标文字为 15–20px、300 字重，使用 0.16–0.28em 正字距；中文不得使用负字距。
- 标题通常占 2–3 行，保持大面积呼吸空间。不要为了塞入内容把正文缩成微小参数字。

【可复用版式】
1. 封面：顶部双标签，中部偏下放 2–3 行大标题、短副标题和少量元信息。
2. 核心观点：大标题居于光核区域，一段解释用左侧细线强调，下方可放简短流程坐标。
3. 步骤页：3–4 条纵向编号行，每行由编号、短标题和解释组成；手机端不做三列卡片。
4. 对比页：最多两列，每列用顶部细线、标签、标题和纵向要点构成；正文较长时改为上下排列。
5. 检查清单：4–6 条通栏信息行，以小方框、标题和短编号形成扫描节奏。
6. 收尾页：一句大总结、短说明和 2–3 条纵向或横向代码式提示；内容较长时最多两列。
- 每页只选择一种主信息结构，不为了展示模板能力而堆叠所有组件。

【内容处理】
- 标题、正文、数字、术语和结论必须来自用户内容；示例中的 AI 工作流文案、年份、标签和账号都不能复制到新任务。
- 英文只作辅助标签；用户内容以中文为主时，英文不得承担核心信息。
- 未提供数据时，不得虚构参数、坐标、年份或编号含义。页码可以按实际页序生成。
- 页面内容装不下时优先拆页、减少装饰或调整正文密度，不裁切正文，也不破坏视觉焦点。

【输出自检】
- 检查所有卡片是否保持 1080×1440、无外框、无横向溢出。
- 检查青蓝光核是否仍是背景气氛，而不是影响文字对比度的主角。
- 检查每页是否只有一个清晰重点，正文是否能在手机截图中直接阅读。
- 检查页脚、标题与正文是否都在正常文档流中，标题多换一行也不会发生重叠。
