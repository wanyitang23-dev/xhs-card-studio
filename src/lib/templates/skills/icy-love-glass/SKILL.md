【模板：冰蓝玻璃编辑风】
【意图】把教程、清单、个人成长、情绪观点和轻生活方式内容，做成梦幻但仍然清楚易读的小红书竖版图文。

【结构 — 硬性要求】
- 无框架、无 JS。`body` 内只有一个 `.deck`，纵向排列若干 `.card`，卡间距 24px；`.deck` 不加 padding，不得出现黑色外框。
- `*{box-sizing:border-box}`；每张卡固定 `width:1080px;height:1440px;overflow:hidden;position:relative`。
- `.deck` 与 `.card` 使用 `margin-inline:auto`，窄窗口下保持左侧可滚动。
- 卡片骨架：顶部英文小标签与页码 → 主标题/正文 → 底部主题词与页序。
- 页面数量服从用户选择；自动模式按内容长度分页。保留原文模式必须逐字覆盖全文，只改变分页和排版。
- 一页有空间不等于空页面。非封面页必须承载一个完整观点及其解释，或 2-4 个紧密相关的信息项。
- 内容装不下就拆页或降低字号，不得溢出裁切；不要为了少页数把正文缩到手机上看不清。

【固定视觉系统】
- 页面底色为冰蓝 `#d9edf9`；内容文字用深海蓝 `#23657f`；高亮用亮蓝 `#2879c8`；雾白卡片用 `rgba(248,252,255,.72)`。
- 背景使用多层 CSS 径向渐变重建冰蓝雾光和边缘玻璃感，不依赖参考图片或外部图片资源。
- 柔焦光斑只承担氛围，不得压住标题与正文；不要把参考图中的文字、品牌或完整海报铺进模板。
- 所有文字都必须是 HTML 文本。正文承载在半透明雾白面板上，用 1-2px 青蓝描边、34-44px 圆角、轻柔内高光和低透明阴影。
- 不使用纯黑、黑色边框、厚重投影、霓虹色或高饱和渐变。玻璃装饰只在边缘出现，不得压住标题与正文。

【字体与排版】
- 英文展示字与大数字用 `Bodoni Moda` / Didot；中文大标题用 `Noto Serif SC`，正文用 `Noto Sans SC`。
- 封面标题 104-122px、行高 0.98-1.06；内容标题 66-88px；正文 28-34px、行高 1.55-1.75。
- 顶栏、标签和页脚 16-22px，英文大写，字距 0.14-0.2em。
- 大标题通常断成 2-3 行。中文正文每行控制在舒适长度，不使用 `ch` 作为宽度单位。

【可复用版式池】
1. 封面：英文眉题 + 2-3 行中文大标题 + 一句短引言；不要塞正文列表。
2. 单观点页：一个大序号、一句核心判断和一块雾白解释面板。
3. 清单页：2-4 个纵向玻璃信息条；每条使用“编号 / 短标题 / 一句解释”。
4. 对比页：上下两块或左右两块大面板；手机端最多两列，内容稍长时改为纵向。
5. 步骤页：纵向 3-4 步，每步有动词标题和短说明。
6. 数据页：1 个大数字 + 1-3 条解释，不得编造用户没有提供的数据。
7. 收尾页：一句总结 + 2-3 条行动提醒 + 关注/收藏提示。
- 同一个版式可以复用，但相邻页面应改变主内容结构，避免连续多页看起来完全相同。
- 英文只作为辅助标签。除非用户原文就是英文，不得用英文替代中文信息。

【内容处理】
- 标题与正文必须来自用户内容；示例里的爱情词汇、AI 习惯、数字、账号和页数都只是演示，不得复制到新任务。
- 每条信息只出现一次，不要先放完整段落，再在下方拆成重复摘要。
- 保留原文时一字不改；精简提炼时可以改写为适合卡片的短句，但不能改变事实或编造数据。
- 页脚账号严格使用用户输入；未提供账号时改放本页主题词，不得虚构账号。
